DEVOPS GUIDE

DevOps = Development and Operations

Development: - Test - Code - Deploy

Operations: - Deploy - Operate


STEP 1: LINUX FUNDAMENTALS

-   OS fundamentals
-   CLI (Bash)
-   Processes and permissions: ps, kill, chmod
-   Package management: apt, yum
-   Text editors: vim


STEP 2: NETWORKING AND SECURITY CONCEPTS

-   TCP/IP and OSI models
-   Different protocols: HTTP, HTTPS, SSH, etc.
-   IP addressing, subnetting, DNS
-   Network issues and troubleshooting
-   Firewalls and proxy servers
-   Wireshark (network analysis tool)


STEP 3: SCRIPTING AND PROGRAMMING

Languages: - Python - Ruby - Golang

Topics: - Syntax and fundamentals - Useful libraries - File handling
- Writing automation scripts


STEP 4: VERSION CONTROL (GIT)

-   Important Git commands: init, clone, add, commit, push, pull,
    merge, rebase, etc.
-   Concept of branching
-   Merging and merge conflict resolution
-   Working with remote repositories


STEP 5: CLOUD

Popular options: AWS, Azure, GCP (Google Cloud Platform)

-   Configure and manage servers and data (EC2, S3, RDS)
-   Manage users, groups and roles (IAM)
-   Set up and manage isolated networks (VPC)


STEP 6: MICROSERVICES AND CONTAINERS

Popular option: Docker

-   Overview of virtualization and containerization
-   Docker images and managing containers
-   Docker commands: run, ps, build, etc.
-   Writing Dockerfiles
-   Using Docker Compose


STEP 7: CI/CD - CONTINUOUS INTEGRATION AND CONTINUOUS DEPLOYMENT

Popular options: Jenkins, GitHub Actions CI/CD, GitLab CI,
CircleCI, Travis CI


STEP 8: INFRASTRUCTURE AS CODE (IaC)

Environments: Dev, Test, Stage, Prod

Provisioning:
-   Terraform - Declarative approach
-   Alternative: Pulumi

Configuration management:
-   Ansible
-   Alternatives: Puppet, Chef


STEP 9: ORCHESTRATION AND MANAGEMENT

Popular option: Kubernetes

-   Creating and managing K8s clusters
-   Deployment of applications on K8s
-   K8s commands: apply, build, delete, etc.


STEP 10: MONITORING AND LOGGING

Popular options: Prometheus, Grafana

Alternatives: ELK, Fluentd, AWS CloudWatch
